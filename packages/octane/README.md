# @nstudio/nativescript-compiler-octane

Octane adapter for [`@nstudio/nativescript-compiler`](https://www.npmjs.com/package/@nstudio/nativescript-compiler), enabling NativeScript Octane apps (`@nativescript-community/octane`) to compile directly to native code with no JavaScript runtime.

## Installation

```bash
ns extension install @nstudio/nativescript-compiler
npm install --save-dev @nstudio/nativescript-compiler-octane
```

Install the adapter at the same version as `@nstudio/nativescript-compiler`.

## Usage

```bash
ns compile ios
```

> Note: Octane compiled builds currently target iOS only.

## Supported Versions

- `@nativescript-community/octane`: `>=0.2.4 <0.3.0`
