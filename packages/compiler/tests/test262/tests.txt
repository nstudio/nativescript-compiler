# Left out, one line each:
#   built-ins/Proxy, built-ins/Reflect: refused by design.
#   built-ins/Atomics, built-ins/SharedArrayBuffer: refused by design.
#   built-ins/FinalizationRegistry: refused by design.
#   built-ins/Function (except prototype/apply, bind, call): the Function constructor builds code from text (refused
#     by design); toString, caller and arguments reflect over a function's source and frames (harness reflection).
#   built-ins/GeneratorFunction, AsyncFunction, AsyncGeneratorFunction: these constructors build functions from text
#     (refused by design).
#   built-ins/Temporal, intl402/Temporal: not in the target library (ES2023, src/program/program.ts).
#   built-ins/Set/prototype set methods (union, intersection, …): not in the target library.
#   built-ins/Math/sumPrecise, f16round; built-ins/Promise/try, allKeyed, allSettledKeyed: not in the target library.
#   built-ins/String/prototype/isWellFormed, toWellFormed: not in the target library (ES2024 string).
#   built-ins/RegExp/unicodeSets (the v flag), regexp-modifiers, escape: not in the target library.
#   built-ins/RegExp/property-escapes: its harness (regExpUtils.js, buildString) is not ported.
#   built-ins/ShadowRealm, AbstractModuleSource, DisposableStack, AsyncDisposableStack, SuppressedError: not in the
#     target library.
#   annexB: Annex B.
#   staging: proposals, not yet in the specification.
#   harness: test262's checks of its own harness (self/ holds the ported harness's).
#   language/eval-code, language/statements/with: refused by design.
#   language/module-code, language/import, language/export: module fixtures and host loading (harness reflection).
#   Everything else in test262 (other built-ins, and language/ beyond the areas above) is not selected yet. It is not
#   excluded for a cause: it is untested here.
