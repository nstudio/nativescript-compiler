# @nstudio/nativescript-compiler-vue

Vue adapter for [`@nstudio/nativescript-compiler`](https://www.npmjs.com/package/@nstudio/nativescript-compiler), enabling NativeScript Vue apps (`nativescript-vue`) to compile directly to Swift (iOS) and Kotlin (Android) with no JavaScript runtime.

## Installation

```bash
ns extension install @nstudio/nativescript-compiler
npm install --save-dev @nstudio/nativescript-compiler-vue
```

Install the adapter at the same version as `@nstudio/nativescript-compiler`.

## Usage

```bash
ns compile ios
ns compile android
```

## Supported Versions

- `nativescript-vue`: `>=3.1.0 <4.0.0`
