# @nstudio/nativescript-compiler-react

React adapter for [`@nstudio/nativescript-compiler`](https://www.npmjs.com/package/@nstudio/nativescript-compiler), enabling NativeScript React apps (`react-nativescript`) to compile directly to Swift (iOS) and Kotlin (Android) with no JavaScript runtime.

## Installation

```bash
ns extension install @nstudio/nativescript-compiler
npm install --save-dev @nstudio/nativescript-compiler-react
```

Install the adapter at the same version as `@nstudio/nativescript-compiler`.

## Usage

```bash
ns compile ios
ns compile android
```

## Supported Versions

- `react-nativescript`: `>=5.0.0 <6.0.0`
- `react`: `>=18.2.0 <19.0.0`
